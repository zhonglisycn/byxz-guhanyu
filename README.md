# 古汉语词典

小米手环 10 上的古汉语词典，3015 条。读文言文、古诗时随手查一下用。

打拼音或直接打汉字都行，繁体也能查（`給` 会跳到 `给`）。词条按「词性 · 今译 · 例句 · 出处」分开显示，
例句都有出处，没把握的不硬凑。

- 包：`dist/古汉语词典_byxz.bin`，约 481 KB
- 包名 `com.byxz.guhanyu`，版本 3.3.1

## 收了些什么

单字（常用字加文言常用字）、古今异义复词（妻子、中国、地方、无论、行李这类）、偏义复词（缓急、存亡、异同、作息）、
典故成语（破釜沉舟、负荆请罪、图穷匕见、闻鸡起舞……）、诗词意象（明月、流水、晓风残月、锦书、兰舟、胡笳、戍鼓）、
名物词（衣食住行、礼器兵器、乐舞文具）、人物地名（伯夷、苏武、祖逖、岳飞、长安、洞庭、黄鹤楼）、
文学语汇和节气时令。

单字其实早就收得差不多了（1087 个，其中不少是繁体字头，构建时会自动建简体别名）。真正缺的是多字词，
原来只有 192 条，这几批补的就是这一块。

## 怎么用

进"查字"页，点搜索框弹键盘，打拼音出候选，点一个字看解释。也可以直接在搜索框里打汉字。

## 踩过的坑

**词库不能每个页面各带一份。** Vela 打包会把 import 的模块内联进每个页面的 jsc。3015 条词库约 650 KB，
早先每个页面各带一份，开机要啃大约 1.4 MB 字节码，表现就是"打不开、一进就重启"。现在词库只在 app.ux 载入一份，
页面只 import 不含数据的 `common/core/dict-format.js`：`lookup.jsc` 从 794 KB 降到 72 KB，整包从 1468 KB 降到 481 KB。

**选候选字会重启**。选字那一下，组件要做候选重算加重渲染，页面同时在查词渲染，两波负载叠在同一帧会被看门狗杀掉。
现在查词和候选重算都分帧执行。

**字体安全检查**。手环只保证 GB2312 字形，`tools/check-font.mjs` 会拦下正文里渲染不出的字。写内容时被抓过
浥、鹖、蘋、冏、筼、筜、曌 这七个。

**例句必须有出处**。`tools/lexicon.test.mjs` 里有硬性检查，防止拿现代词冒充例句。

## 构建

```bash
npm install
node tools/build-words.mjs      # words*.js → lexicon.js（用 Unihan 补拼音、部首、笔画、繁体别名）
bash tools/run-tests.sh         # 内核测试 45 项 + 字体安全检查
bash tools/build-bin.sh         # 输出 dist/古汉语词典_byxz.bin
```

词条写在 `src/common/data/words*.js` 里，构建脚本按 `words\d*.js` 全部收进去。格式：

```js
字头: '词性|今译; 词性|今译|例句|出处'
```

有例句就得写出处，没把握出处就只写今译。
