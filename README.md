# 古汉语词典（byxz）

小米手环 10（Vela 快应用）上的**古汉语 / 文言词典**：打拼音或汉字查词，按「词性 · 今译 · 例句 · 出处」分段显示，例句一律有名篇出处。面向读文言文、古诗时的随手查证。

- 产物：`dist/古汉语词典_byxz.bin`（约 481 KB）
- 包名：`com.byxz.guhanyu`，版本 3.3.1
- 屏幕：212×520 胶囊屏（上下各是半径 106px 的半圆，可用区约 174×420）
- 词库：**3015 条**（本项目人工撰写）

## 2. 用法

1. 首页 → **查字**
2. 点标题栏下的搜索框 → 键盘弹出（默认中文拼音键盘）
3. 打拼音（`wo` / `qizi`）→ 候选字出现 → 点一个字看解释；也可直接打汉字
4. 词条页按「词性 · 今译 · 例句 · 出处」分段；「看全部 N 条」进入完整义项
5. 繁体、异体写法都能查（如 `給` → 给、`說` → 说）
6. 收藏与历史存在本机

## 3. 工程要点（踩过的坑，写在源码注释里）

- **词库数据只进 app 一处**：Vela 打包会把 import 的模块**内联进每个页面的 jsc**。3015 条词库约 650 KB，早期版本每个页面各带一份，真机启动要啃约 1.4 MB 字节码 —— 表现是"打不开、一进就重启"。现在词库只在 `app.ux` 侧载入一份，页面只 import 不含数据的 `common/core/dict-format.js`：`lookup.jsc` 从 794 KB 降到 72 KB，整包从 1468 KB 降到 481 KB。
- **选字重启**：选候选字时组件要做一次候选重算 + 整棵键盘子树重渲染，页面同时查词渲染，两波负载叠在同一帧会触发看门狗。已把查词与候选重算分帧（`setTimeout`）。
- **字体安全检查**：手环只保证 GB2312 字形，`tools/check-font.mjs` 会拦截正文里渲染不出的生僻字（开发中抓出过 浥、鹖、蘋、冏、筼、筜、曌）。
- **例句必须有出处**：`tools/lexicon.test.mjs` 里有硬性断言（阈值 <20 处），防止拿现代词冒充例句。
- 胶囊屏几何：键盘整体避让下半径 106px 的弧区，键不能落进弧里。

## 4. 构建

```bash
npm install                     # 依赖 aiot-toolkit
node tools/build-words.mjs      # 数据 words*.js → lexicon.js（含 Unihan 拼音/部首/笔画与别名）
bash tools/run-tests.sh         # 内核测试（45 项）+ 字体安全检查
bash tools/build-bin.sh         # 校验 + 编译，输出 dist/古汉语词典_byxz.bin
```

数据分文件写在 `src/common/data/words*.js`（构建脚本按 `words\d*.js` 自动全收），格式：

```js
字头: '词性|今译; 词性|今译|例句|出处'
// 词性用单字：名 动 形 副 介 连 助 代 量 数 叹 兼 通
// 写法要求：有例句就必须有出处；拿不准出处就只写今译（宁缺勿错）
```

## 5. 数据来源与许可

- **词条正文**：本项目人工撰写（词性 · 今译 · 例句 · 出处），例句为公版古籍原文。
- **拼音 / 部首 / 笔画 / 繁体别名**：来自 [Unihan](https://unicode.org/charts/unihan.html)（Unicode License）。
- **输入法组件**：`src/components/InputMethod/` 取自开源项目 [NEORUAA/Vela_input_method](https://github.com/NEORUAA/Vela_input_method)（MIT），本项目仅改了几何基准（按 212px 屏宽重排）与性能相关的几处（懒挂载、`flex-shrink`、候选分帧），其许可证与署名见该目录。
- 本项目代码以 **MIT** 许可发布，见 `LICENSE`。
